## 1. Course Outcomes (COs)

Upon successful completion of the course, students should be able to:

-   **CO1:** Describe the fundamental concepts and principles of
    software design.
-   **CO2:** Explain the importance of software design principles in
    developing maintainable software.
-   **CO3:** Analyze basic software design concepts, including coupling,
    cohesion, abstraction, and encapsulation.
-   **CO4:** Explain common software architectural styles and design
    patterns.
-   **CO5:** Apply fundamental software design principles to develop
    solutions for simple software problems.

## 2. Assessment Questions

### Section A: Knowledge (C1 -- Remember)

**Total Marks: 10**

**Q1. Answer the following questions briefly.** (5 × 2 = 10)

a)  Define software design. (2)

b)  What is modularity in software design? (2)

c)  Define coupling. (2)

d)  Define cohesion. (2)

e)  What is a software design pattern? (2)

### Section B: Understanding (C2 -- Understand)

**Total Marks: 15**

**Q2. Answer the following questions.** (2 × 5 = 10)

a)  Differentiate between coupling and cohesion in software design. (5)

b)  Explain the concepts of abstraction and encapsulation with suitable
    examples. (5)

**Q3.** What is the Model-View-Controller (MVC) architectural pattern?
Explain the responsibilities of its three components: Model, View, and
Controller. (5)

### Section C: Application (C3 -- Apply)

**Total Marks: 15**

**Q4. Answer the following questions.** (2 × 5 = 10)

a)  Consider a Student Management System consisting of separate modules
    for student registration, attendance management, and result
    processing. Explain how modularity improves the maintainability of
    this system. (5)

b)  A software class is responsible for performing several unrelated
    tasks. Explain how you would redesign it to improve its cohesion.
    (5)

**Q5.** You are assigned to design a simple Online Shopping System.
Identify three essential software modules and briefly describe the
responsibility of each module. (5)

## 5. Outcome-Based Education (OBE) Alignment

This assessment follows an outcome-based approach through the following
features:

1.  **Outcome-oriented assessment:** Questions are intended to evaluate
    the stated Course Outcomes.
2.  **Cognitive progression:** Questions progress from remembering
    fundamental concepts to understanding and applying software design
    principles.
3.  **Measurable assessment:** Each question has a defined mark
    allocation.
4.  **CO mapping:** Questions are mapped to relevant Course Outcomes.
5.  **BNQF consideration:** The assessment considers knowledge,
    understanding, and application within an outcome-based learning
    structure.
